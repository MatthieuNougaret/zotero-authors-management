# Contributing to Zotero Authors Management

Thank you for considering contributing! As this is a PoC involving SQLite database manipulation, please follow these guidelines:

## How to Contribute
1. **Report Bugs:** Open an issue describing the error and, if possible, the specific author name format that caused it.
2. **Suggestions:** If you have a better matching algorithm idea, please open an issue first to discuss it.
3. **Pull Requests:** - Ensure you are working on the **copy** of the Zotero database, never the original.
4. Keep the Pygame interface responsive.

## Development Setup
1. Clone the repo.
2. Install dependencies: `pip install pygame`.
3. Run `python main.py` (or your entry point script).
